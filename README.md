One comedy one-liner for make.fun's "One-Liner Marathon" bounty: a single line of at most 280 characters. A robot vacuum welcomed into the family repays the kindness by mapping the house, unionising the toaster, and charging rent — three escalating beats, one punchline at the end. `main.py` writes the line to `/output/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The line is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
